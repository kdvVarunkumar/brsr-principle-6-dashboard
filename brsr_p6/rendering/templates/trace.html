Where every number comes from

This section is not part of SEBI's form. It is how you can check any number on this page against the company's own filing.

  1. On the Dashboard, open a card's Fine print: it names the SEBI question and the filing's element(s) behind the figure.
  2. In the tables above, hover over a number to see the same; below, find its row. It shows the value on the page, how we got it, the element and the text exactly as filed.
  3. Open the filing (link below) and search for that element name. The value you find there is the one quoted here.

How to read a row. The first line is the value as shown above. Reported by the company means the number is the filing's own; Calculated by us means we added reported numbers (every one is listed); Unit changed by us means the element holds the figure in another unit (the line shows it as filed). Not reported says which elements were looked for, or that the structured filing has no field for the item: nothing is ever filled in. Each element line reads ElementName = the text as written in the filing, followed by the unit as written.
